# AI 发电 · AIFADIAN

把一件 AI 作品，讲清楚。

**线上地址**：https://crazyprince01057.github.io/

一个独立创作者社区的公开工具首版：在浏览器里把一件作品的用途、人工取舍、AI 参与环节和公开边界整理成一页说明，可复制或下载；也开放早期共建（带一件有权公开的作品，一起写清它的说明）。

## 当前边界

- 纯静态页面，无账号、无支付、无作品托管、无云同步，不调用模型。
- 填写内容只保存在访问者自己的浏览器里，本站不收集联系方式。
- 页面中的示例均为模板演示，不代表真实作者或经营数据。
- 本项目为独立原创实现，与爱发电（afdian）平台无隶属或授权关系。

## 本地运行

任意静态服务器即可，例如：

```bash
python -m http.server 8080
# 打开 http://127.0.0.1:8080/
```
