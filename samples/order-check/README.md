# 订单核对工具 · 合成演示样例与适配说明

版本：order-check 1.0.0 ｜ 契约 1.0 ｜ 发布日期 2026-10-17

## 这里有什么

两组**合成演示数据**（不含任何真实订单信息），用于练手和验证工具行为：

| 目录 | 内容 | 规模 |
| --- | --- | --- |
| `basic/` | 常规改单：改数量、取消、新增 | 3 行小表 |
| `boundary/` | 混合边界：重复订单号、空编号、非法日期、前导零编号等 | 19 行 |

每组四个文件：

- `old.csv` / `new.csv` —— 工具输入（旧表、新表）
- `expected_diff.csv` —— 预期差异报告
- `expected_exceptions.csv` —— 预期异常明细

## 适配说明（输入要求）

- 只吃 **CSV**（UTF-8），表头固定四列：`订单号,数量,交期,备注`
- **一单一行**；不支持 XLSX 直读（请先另存为 CSV），不自动识别任意表格
- 遇到重复订单号、空编号、非法日期：工具**不乱猜、不悄悄合并**，全部列入异常明细等人工确认

## 如何验证

用工具对 `old.csv` + `new.csv` 跑一遍，输出的差异报告与异常明细应与 `expected_*.csv` **逐字节一致**；摘要中的计数与输入散列也应吻合。工具本体目前通过小红书内测发放（账号见站点「创作者入驻 / 一起共建」区）。
